# Smart Habit Tracker

A clean and minimal habit tracking web app built with **pure HTML, CSS, and Vanilla JavaScript**.

## Features

- Add habits with custom colors
- Mark habits as completed for today
- Daily progress indicator
- Automatic streak calculation
- Persistent data using localStorage
- Dark mode support
- Fully responsive layout

## Tech stack

- HTML5
- CSS3 (modern, minimal UI)
- Vanilla JavaScript (no frameworks)

## How it works

- Each habit stores completion dates
- Streaks are calculated by checking consecutive completed days
- Daily progress is based on completed habits for today
- Data is saved automatically in localStorage
- Theme preference is persisted

## Purpose

This project is designed as a **portfolio-quality frontend project** demonstrating:

- State management without frameworks
- Clean DOM manipulation
- UI/UX attention
- Real-world app logic
